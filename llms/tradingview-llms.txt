# TradingView

> TradingView is a charting, social, and market-data platform for traders and investors. Its developer surface is delivered as client-side, embeddable UI components and self-hosted JavaScript charting libraries — the open-source Lightweight Charts library, the free self-hosted Advanced Charts (Charting Library), the Trading Platform library, and a catalog of copy-paste embeddable widgets — plus a Broker Integration REST API that brokerages implement to enable in-chart trading. There is no public hosted market-data REST API.

## Developer Products
- [Lightweight Charts](https://www.tradingview.com/lightweight-charts/): Open-source (Apache-2.0) HTML5-canvas financial charting library; npm `lightweight-charts`.
- [Advanced Charts (Charting Library)](https://www.tradingview.com/advanced-charts/): Free, self-hosted charting solution with a custom Datafeed API.
- [Trading Platform](https://www.tradingview.com/trading-platform/): Advanced Charts plus in-chart trading via the Broker API.
- [Embeddable Widgets](https://www.tradingview.com/widget/): Copy-paste financial widgets (charts, tickers, heatmaps, screeners, calendars).
